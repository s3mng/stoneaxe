<h1 align="center">Stoneaxe</h1>

<p align="center">메뉴 막대 위 작은 곡괭이. 실제 비트코인 블록을 향한 도전.</p>

<p align="center"><a href="README.md">English</a> · <b>한국어</b></p>

Stoneaxe는 [CKPool](https://solo.ckpool.org/)을 통해 비트코인을 솔로 채굴하는
macOS 네이티브 앱입니다. 수신 주소를 저장하면 메뉴 막대의 픽셀 곡괭이가 움직이며
맥에서 실제 해시 계산을 수행합니다.

재미를 위한 프로젝트입니다. 맥으로 블록을 발견할 확률은 매우 낮으며,
**share 승인은 수익이 아닙니다.**

## 주요 기능

- **Metal 채굴:** Apple Silicon GPU에서 SHA-256d를 계산하고 제출할 결과는 CPU에서 재검증합니다.
- **자동 조절:** 사용 중에는 가볍게, 자리를 비우면 서서히 강도를 높이고 작업 지연 시 양보합니다.
- **발열 대응:** 시스템 발열에 따라 감속·중지하고 냉각 시간을 둡니다.
- **메뉴 막대 곡괭이:** 애니메이션, 빠른 일시정지·재개, 동작 줄이기 지원.
- **통계:** 현재·평균 해시레이트, 이번 실행·오늘·전체 채굴 시간, share 결과, 최고 난이도, 메모리 사용량과 JSON 내보내기.
- **블록 알림:** 후보 발견·풀 승인·메인 체인 포함을 구분하며 후보 기록은 재시작 후에도 유지됩니다.
- **로그와 설정:** 검색, 순환 로그 파일, 한국어·영어, 로그인 시 실행. 배터리 채굴은 기본으로 꺼져 있습니다.

## 설치

```sh
brew tap s3mng/stoneaxe https://github.com/s3mng/stoneaxe
brew install --cask s3mng/stoneaxe/stoneaxe
```

현재 Stoneaxe는 임시 서명(ad-hoc)을 사용하며 Apple 공증을 받지 않았습니다.
macOS가 최초 실행을 막으면 Finder에서 **응용 프로그램**을 열고 **Stoneaxe**를
Control-클릭한 뒤 **열기**, 다시 **열기**를 선택하세요. 이 예외는 Stoneaxe에만 적용됩니다.

Apple Silicon과 macOS 14 이상이 필요합니다.

### 소스에서 빌드

**Apple Silicon 맥**, **macOS 14 이상**, **Swift 5.9 이상**을 포함한 Xcode 또는
Command Line Tools가 필요합니다. 외부 패키지 의존성은 없습니다.

```sh
git clone https://github.com/s3mng/stoneaxe.git
cd stoneaxe
swift test
bash scripts/build-app.sh
open dist/Stoneaxe.app
```

로컬 빌드는 임시 서명(ad-hoc)을 사용합니다. 알림과 로그인 항목 연동을 위해
`swift run` 대신 생성된 `.app`을 실행하세요.

## 시작하기

1. **설정**에 Sparrow 등 지갑의 비트코인 메인넷 수신 주소를 붙여넣습니다.
2. **자동 채굴 활성화**를 켜고 **저장 및 적용**을 누릅니다.
3. 블록 발견 알림을 받으려면 macOS 알림을 허용합니다.

공개 수신 주소만 필요합니다. **시드 문구나 개인 키는 입력하지 마세요.**
Sparrow는 계속 켜두지 않아도 됩니다.

설정의 **연결 테스트**로 저장 전에 서버 접속·주소 인증·채굴 작업 수신을 확인할
수 있습니다. 입력한 공개 주소로 CKPool에 최대 20초간 별도 연결하며, 채굴하거나
share를 제출하지 않습니다. 기존 채굴은 유지됩니다. 실제 share 승인 여부를
검사하는 기능은 아닙니다.

곡괭이를 클릭하면 해시레이트 확인과 일시정지가 가능합니다. 앱 창에서는 통계,
로그, 블록 기록과 설정을 볼 수 있습니다. 창을 닫아도 실행은 유지되며,
**Stoneaxe 종료**를 누르면 멈춥니다.

## 자동 조절 방식

| 상황 | 기본 동작 |
| --- | --- |
| 맥 사용 중 | 낮은 5% 채굴 시간 예산 |
| 5분간 입력 없음 | 20%까지 서서히 증가 |
| 입력 재개 | 낮은 예산으로 복귀 |
| GPU 작업 지연 | 작업 크기를 줄이고 잠시 양보 |
| 발열 상승 | 감속·중지, 심한 발열 후 냉각 대기 |
| 배터리 사용 | 별도로 허용하지 않으면 중지 |
| 잠자기 | 작업 중지, 깨어나면 재연결 |
| GPU 검증·실행 오류 | 채굴 중지, 앱 재시작 후 재시도 |

예산은 **우리 계산 시간과 쉬는 간격**을 조절하는 값이며 전체 GPU 사용률이
아닙니다. 짧은 작업을 하나씩 제출하며 비공개 GPU 사용률 API를 사용하거나
시스템 잠자기를 막지 않습니다. 모든 환경에서 성능 영향이나 드라이버 문제를
없앤다고 보장하지는 않습니다. 메모리 100MB 미만도 실측 목표이며 보장된 상한은 아닙니다.

## Share와 블록

**Share**는 풀에 제출하는 작업 증명입니다. 승인은 정상 동작의 지표이며 솔로
채굴에서 보상을 적립한다는 뜻은 아닙니다. 첫 share가 늦게 나와도 로컬 계산은
정상일 수 있습니다.

**블록 후보**는 네트워크 난이도를 만족한 로컬 결과입니다. CPU 재검증 후 제출하고
기록과 알림을 남깁니다. 풀의 share 승인만으로 블록 포함을 확정하지 않습니다.

네트워크 확인을 켜면 mempool.space에서 정확한 헤더와 메인 체인 포함을 확인합니다.
체인 포함·제외와 확인 100회 도달 시 알림을 보낼 수 있습니다. 앱 실행 중 최대
분당 한 번, 발견 후 7일 또는 확인 100회까지 추적합니다. 조회 실패는 대기로 남습니다.
성숙 알림은 **지갑의 사용 가능 잔액 검증이 아닙니다.**

현재 수수료와 조건은 [CKPool 공식 사이트](https://solo.ckpool.org/)를 참고하세요.

## 개인정보와 로컬 데이터

분석용 추적이나 가입 절차는 없습니다.

- **CKPool:** `stratum.ckpool.org:3333`, 작업자 이름은 `<수신 주소>.stoneaxe`입니다. Stratum V1은 암호화되지 않습니다.
- **mempool.space (선택):** 블록 후보 발견 후 해시와 접속 IP가 전달됩니다. 블록 보기 링크도 탐색기에 접속합니다.

| 데이터 | 위치 |
| --- | --- |
| 설정·공개 수신 주소 | `app.stoneaxe.mac` UserDefaults |
| 통계·블록 기록 | `~/Library/Application Support/Stoneaxe/statistics.json` |
| 로그 | `~/Library/Logs/Stoneaxe/` |

로그에는 원본 풀 메시지, 주소, 인증 정보와 extranonce를 남기지 않습니다.
파일은 약 1MB마다 순환해 4개를 보관하고 화면은 최근 300개를 유지합니다.
파일은 영문, 화면은 선택한 언어로 표시합니다. 통계는 90일간의 일별 요약과
전체 누적값을 저장합니다. **내보내기에는 블록 기록의 주소가 포함될 수 있으니** 공유 전에 확인하세요.

## 개발

```sh
swift test
dist/Stoneaxe.app/Contents/MacOS/Stoneaxe --self-test
```

GPU 자체 검증은 네트워크 접속 없이 제네시스 블록과 합성 작업을 CPU 결과와
비교합니다. 실제 Apple Silicon GPU가 필요하며 앱 시작 시에도 검증합니다.

구조·아이콘 생성·검증·Homebrew 배포 과정은 [개발 가이드](docs/DEVELOPMENT.md)를 참고하세요.
